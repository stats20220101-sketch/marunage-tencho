# 社内向け　方向性の確認（そのまま貼り付け可）

---

お疲れ様です。久茂地店のガス設備の件、進め方を以下で考えています。ご確認ください。

## 方針

揉めずに終わらせることを優先します。建替え後の新ビルへの入居も条件次第で検討しているため、家主のアートマン様との関係維持を重視します。立退料などの交渉は今回持ち出しません。

ただし「言った言わない」を防ぐため、**最後に簡単な書面は残します。**

## 進め方

1. **田頭さんから電話**でアポイントを取る
2. **面談**（協和ガスさんに同席いただく）
3. その場で「建替えまでは現状のまま」を口頭で確認
4. **後日、覚書を持参して押印**

書面を先に送ると「筋を通していない」と受け取られる恐れがあるため、**必ず面談を先**にします。家主様ご本人が「直接会って話したい」と書面で求めておられます。

## 面談での留意点

- ご相談が事前にできていなかった点はお詫びする（ただし「無断で設置した」と認める言い方はしない）
- 設置経緯の是非は議論しない
- 屋上ダクトの件は必ず出るので、**その場で約束せず、回答期限を切って持ち帰る**
- 建替え後の入居に関心がある旨は伝える
- 立退料・弁護士の話はしない

## 確認いただきたいこと

1. この方向で進めてよいか
2. **田頭さんへ**：アートマン様との話し合いで、「残り3年」とは**いつまで**という理解でしたか（◯年◯月まで／建替え着工まで）
3. **田頭さんへ**：その場で、建替え時の退去について何か話は出ましたか
4. 屋上ダクトの件、改善する方針はあるか（面談で必ず聞かれます）

あわせて、書面の空欄を埋めるため以下をお願いします。

- 三社の正式名称・住所・代表者名
- 物件表示（丁目番地、階、面積）
- GHP空調機の台数、ガスバルクの基数

◯月◯日までにご返信いただけますと助かります。よろしくお願いします。
