# ガス設備の継続設置及び使用に関する覚書

＿＿＿＿＿＿＿＿＿＿＿＿＿＿（以下「甲」という。）、＿＿＿＿＿＿＿＿＿＿＿＿＿＿（以下「乙」という。）及び協和ガス株式会社（以下「丙」という。）は、甲が所有し管理する後記物件の表示記載の建物（以下「本件建物」という。）内において乙が営業する店舗（以下「本件店舗」という。）に係るガス設備の設置及び使用に関し、以下のとおり合意し、本覚書を締結する。

## 第1条（目的）

本覚書は、本件建物の建替え工事に着手するまでの間、本件店舗において現に設置され使用されているガス設備を現状のまま継続して設置し、及び使用することについて、甲乙丙三者の認識を明確にし、後日の疑義を防止することを目的とする。

## 第2条（対象設備）

1. 本覚書の対象となる設備（以下「本件設備」という。）は、次のとおりとする。
   1. GHP空調機　＿＿台
   2. ガスバルク貯槽　＿＿基（容量　＿＿kg）
   3. ガス配管、調整器その他の付属設備一式
   4. ガス器具一式
2. 本件設備の所有者は丙とする。
3. 本件設備の設置場所は、本覚書締結日現在における設置場所とし、その詳細は別紙（配置図及び写真）のとおりとする。

## 第3条（継続設置及び使用の承諾）

1. 甲は、丙が本件設備を前条第3項の設置場所において次条に定める期間中引き続き設置すること、及び乙がこれを使用することを承諾する。
2. 甲は、次条に定める期間中、正当な理由なく本件設備の移設、撤去又は変更を求めないものとする。
3. 乙及び丙は、次条に定める期間中、甲の書面による事前の承諾を得ることなく、本件設備の設置場所を変更し、又は新たな設備を増設しないものとする。

## 第4条（期間）

1. 本覚書に基づく本件設備の設置及び使用の期間は、本覚書締結の日から、次の各号に定める日のいずれか早い日までとする。
   1. ＿＿＿＿年＿＿月＿＿日
   2. 本件建物の建替え工事の着手日
2. 甲は、本件建物の建替え工事の時期が具体的に決定したときは、その着手予定日の＿＿箇月前までに、乙及び丙に対し書面によりこれを通知するものとする。
3. 前項の通知の時期又は建替え工事の時期に変更が生じた場合においても、甲は、速やかに乙及び丙に対しこれを通知するものとする。

## 第5条（維持管理及び保安）

1. 丙は、液化石油ガスの保安の確保及び取引の適正化に関する法律その他の関係法令並びに行政庁の指導に従い、自らの責任と費用において本件設備の保安、点検及び維持管理を行うものとする。
2. 本件設備に起因して事故又は損害が生じた場合には、丙がその責任を負うものとする。ただし、乙の故意又は重大な過失に起因する場合は、この限りでない。
3. 丙は、本件設備の保安に関し甲又は乙から連絡を受けたときは、速やかに必要な措置を講ずるものとする。

## 第6条（期間満了時の撤去及び原状回復）

1. 第4条に定める期間が満了したときは、丙は、自らの責任と費用において本件設備を撤去し、その設置場所を原状に回復するものとする。
2. 前項の撤去及び原状回復に要する費用について、乙はこれを負担しない。
3. 撤去の具体的な時期及び方法については、乙の営業に配慮のうえ、甲乙丙が協議して定めるものとする。

## 第7条（本覚書の対象範囲）

本覚書は、本件設備の設置及び使用に関する事項を対象とするものである。本件建物の屋上に設置されたダクトに関する事項その他本覚書に定めのない事項については、本覚書の対象に含まれず、必要に応じて別途協議するものとする。

## 第8条（賃貸借契約との関係）

1. 本覚書は、甲乙間の＿＿＿＿年＿＿月＿＿日付建物賃貸借契約の内容を変更するものではない。
2. 本件建物の建替えに伴う本件店舗の明渡しの時期及び条件については、本覚書はこれを定めるものではなく、別途甲乙間において協議して定めるものとする。

## 第9条（従前の経緯の確認）

甲乙丙は、本件設備の設置に至る従前の経緯のいかんにかかわらず、本覚書の締結をもって本件設備の設置及び使用に関する三者の認識が一致したことを確認し、当該経緯に関し、相互に異議を述べ、又は何らの請求も行わないものとする。

## 第10条（協議）

本覚書に定めのない事項又は本覚書の条項の解釈につき疑義が生じた事項については、甲乙丙が誠意をもって協議のうえ、解決するものとする。

## 各条項の意図

- **第3条第2項** … 本覚書の中核。家主側から「やはり動かしてほしい」と言われない担保。
- **第3条第3項** … 借主・ガス会社側にも義務を課し、一方的に譲歩させる体裁を避けるための条項。
- **第4条第2項** … 建替え時期が前倒しされた場合に突然の対応を迫られないための予告義務。焼肉店は排気・空調設備の移設に時間を要するため、通知期間は6箇月程度を確保することが望ましい。
- **第6条第2項** … 撤去費用が借主に転嫁されないことを明記。
- **第7条** … 屋上ダクトの件を本覚書の対象外と明記。本覚書がダクトの件まで解決したと解釈されること、および逆にダクトを理由に本覚書が否定されることの双方を防ぐ。
- **第8条第2項** … 建替えに伴う明渡しの時期・条件（立退きに関する事項を含む）は本覚書では一切定めないことを明確化。本覚書が明渡しの合意と解釈されることを防ぐための条項であり、削除しないこと。
- **第9条** … 「無断設置であったか否か」の是非に立ち入らず、過去の経緯を相互に蒸し返さない形で処理する条項。
